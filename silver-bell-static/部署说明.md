# 银龄预演 - GitHub Pages 静态部署文件

## 文件说明
此目录包含银龄预演 APP 的静态网页文件，可直接部署到 GitHub Pages。

## 部署步骤

### 1. 克隆你的 GitHub 仓库
```bash
git clone https://github.com/你的用户名/你的用户名.github.io.git
```

### 2. 将此目录的所有文件复制到仓库根目录
将 silver-bell-static 目录中的 **所有文件**（包括 .nojekyll）复制到仓库根目录，覆盖已有文件。

### 3. 提交并推送
```bash
cd 你的用户名.github.io
git add .
git commit -m "部署银龄预演静态版本"
git push origin main
```

### 4. 访问
推送后等待 1-2 分钟，访问 https://你的用户名.github.io/ 即可看到应用。

## 重要说明

- `.nojekyll` 文件非常重要，它告诉 GitHub Pages 不要使用 Jekyll 处理文件，否则 _next 目录下的 CSS 和 JS 文件会被忽略
- 此为静态版本，AI 智能模式不可用。评委切换到智能模式发送消息时，会自动显示提示并切换到演示模式
- 所有其他功能（Demo 模式对话、语音交互、SOS、用药提醒、康养地图等）均可正常使用
- 对话历史保存在浏览器 localStorage 中，不会跨设备同步

## 本地预览
如果想本地预览效果，可以用任意静态文件服务器：
```bash
npx serve silver-bell-static
```
